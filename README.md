# OBS WebSocket Control Panel Example

This example demonstrates how to create a simple web-based control panel to interact with OBS Studio via its WebSocket plugin. It shows how to establish a WebSocket connection, display connection status, and send basic commands like starting/stopping streams and switching scenes using the OBS WebSocket v5 protocol structure.

## Language

`html`

## How to Run

1. Ensure OBS Studio is running with the OBS WebSocket plugin installed and enabled (default port 4444).
2. Save the code as `index.html`.
3. Open `index.html` in a modern web browser.
4. Click the buttons to send commands to OBS.
